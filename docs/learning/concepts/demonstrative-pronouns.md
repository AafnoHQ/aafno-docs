## 2. Learning outcomes

- LO1: Identify single and multiple referents.
- LO2: Choose a form from contextual cues.
- LO3: Distinguish standalone and modifying use.
- LO4: Track a previously mentioned entity.
- LO5: Flag ambiguous reference.

## 3. Meaning and usage

Point to one item or a set using location, shared attention or earlier mention. Establish what both speakers can identify first; physical distance alone need not settle the choice.

## 4. Formation rules

With one book in view, use the first reply and identify the whole participant expression. Add the noun in row 2 and the form instead helps identify that noun. Compare a far shelf with an already discussed object, then repeat with several items.

**Worked models.** यो मेरो हो। / Yo mero ho. / This is mine. Compare यो किताब मेरो हो। / Yo kitaab mero ho. / This book is mine. Use the situations in section 6 to establish the intended readings.

## 5. Variations and agreement

The four forms illustrate working number and distance contrasts; viewpoint, salience and shared context can change interpretation. Review agreement independently.

## 7. Related constructions and contrasts

Standalone demonstrative reference is assessed here. G06-010 owns noun modification; G14 and G08 own case and agreement. A demonstrative can support identification without encoding definiteness on its own.

Related canonical targets: [G06-010](../grammar-catalogue/grammar-foundations.md#g06), [G02-006](interrogative-pronouns.md), [G03-008](definiteness-and-specificity.md), [G14](../grammar-catalogue/relationships-and-transformations.md#g14), [G08](../grammar-catalogue/verbs-and-conjugation.md#g08).

## 8. Anticipated mistakes and corrective feedback

**Likely misunderstanding.** Treating physical distance as the only cue can lead the learner to pick an irrelevant visible object over the one the speakers have just discussed.

**Retry.** Ask what was just pointed at or mentioned, then retry after speakers switch focus. For the contrast target, cover the noun and ask which expression fills the participant slot. Use the [variant-aware assessment policy](../proficiency-framework.md#variant-aware-assessment) for contextual mismatches and unreviewed forms.

## 9. Natural usage

**Draft usage scenario.** An owner answers a question about objects at a stall using rows 1 or 3. Rehearse the exchange with the listener standing elsewhere, then continue by referring to a set already mentioned using row 5. Check the turns with speakers in the intended context before using them as learner-facing models; no frequency or distribution is inferred.

## 10. Prerequisites

- **Required.** an established speaker viewpoint and visible or described items.
- **Helpful.** familiar object vocabulary and number cues.
- **Co-taught.** shared attention and standalone versus modifier comparison.
- **Extension.** case and agreement.

For oral activities, supply enough context through audio or the scene so Devanagari literacy is not an assessment prerequisite.

## 12. Activity types

Row references below refer to the contextual examples in section 6. Use all three language representations by default; adjust visibility only for the evidence target.

### Initial target

- **Learner prompt.** Which item is meant in row 3 if the speakers just discussed the one on the shelf?
- **Expected response.** The shelf item. In another scene the phrase may pick up a different salient referent.
- **Assessment target.** LO4. Record the response against this target separately from the other prototype.
- **Feedback and retry.** Ask what was just pointed at or mentioned, then retry after speakers switch focus.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.

### Contrast target

- **Learner prompt.** Which of rows 1 and 2 uses a standalone form?
- **Expected response.** Row 1; in row 2 the same form modifies the noun.
- **Assessment target.** LO3. Record the response against this target separately from the other prototype.
- **Feedback and retry.** Cover the noun and ask which expression fills the participant slot.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.

## 13. Mastery evidence

Use unseen visible and discourse-only scenes and a standalone-versus-modifier foil. Elicit a form, its referent and the clue, including an ambiguous scene. Record what the answer demonstrates against the local outcomes and keep stem, ending, case, agreement and related semantic evidence separate. Guided performance can inform feedback; mastery requires an independent task and flexible evidence where relevant.
