## 2. Learning outcomes

- LO1: Locate a duration cue.
- LO2: Interpret exact and approximate duration.
- LO3: Distinguish duration from time, frequency and aspect.
- LO4: Produce a suitable reviewed duration expression.

## 3. Meaning and usage

Duration answers how long an event or state holds. It can be approximate, an interval by units or a span such as throughout the day. Keep duration separate from the date or recurrence of the event.

## 4. Formation rules

Ask about a wait and compare a while with a long time. Give a known two-hour span in a second scenario. Compare a span through the day and ask whether the context implies uninterrupted activity before accepting that inference.

**Worked models.** केही बेर / Kehi ber / For a while (Approximate short or unspecified span in a wait context.) Compare धेरै बेर / Dherai ber / For a long time (Approximate longer span as judged in context.) The examples are instructional candidates.

## 5. Variations and agreement

Duration interacts with event type and aspect. Some combinations need boundedness or contextual cues. Detailed clock and numerical formation belongs to G06-011 and tense/aspect to G09.

An event can start in the morning and still be ongoing without an exact duration being stated. Compare the starting-point report in section 6 with the completed two-hour wait. Interpret elapsed length only when endpoints or a measure support it.

## 8. Anticipated mistakes and corrective feedback

A learner can sound plausible while using a cue unrelated to the target. Test what they inferred with the two independent prompts in section 12.

**Corrective cue for the first prompt.** Draw a span with its endpoints unknown and label its length.

**Corrective cue for the second prompt.** If you gave a date or exact number, think about the unspecified length of the wait and retry.

Use the [variant-aware assessment policy](../proficiency-framework.md#variant-aware-assessment) if context permits more than one answer or the variant has not been reviewed.
