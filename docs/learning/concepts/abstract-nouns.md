## 2. Learning outcomes

- LO1: Recognise nouns naming feelings, qualities and ideas.
- LO2: Distinguish abstract and concrete reference.
- LO3: Compare word function in different constructions.
- LO4: Distinguish abstractness from countability.
- LO5: Interpret an unfamiliar contextual use.

## 3. Meaning and usage

Abstract nouns can name feelings, qualities, states or ideas. What is being referred to and how an expression functions in a clause are separate questions.

## 4. Formation rules

Find the idea evaluated in the freedom statement. Then compare happiness as the referent of a noun phrase with a description of the speaker's state. Use the whole expression before assigning a label.

**Worked models.** माया / Maaya / Love or affection Compare दुःख / Duhkha / Sorrow Use the situations in section 6 to establish the intended readings.

## 5. Variations and agreement

Context can individuate a hope or idea, while a concrete substance can be understood by amount. Detailed adjective, nominalisation and derivation analyses stay with their relevant owners.

## 8. Anticipated mistakes and corrective feedback

**Likely misunderstanding.** A learner may assign a fixed function to a feeling word or assume that abstract reference excludes counting.

**Retry.** Compare with evaluating a chair and identify what each expression refers to. For the contrast target, point to the possessor and the predicate in each, then compare the functions before labelling. Use the [variant-aware assessment policy](../proficiency-framework.md#variant-aware-assessment) for contextual mismatches and unreviewed forms.

## 9. Natural usage

**Draft usage scenario.** Two speakers discuss a value using row 4. Later one asks about the other’s mood and hears row 6. Compare this self-description with the observer’s report in row 5. Check the turns with speakers in the intended context before using them as learner-facing models; no frequency or distribution is inferred.

## 10. Prerequisites

- **Required.** understanding of the situation and lexical meaning.
- **Helpful.** basic noun phrase and predicate recognition.
- **Co-taught.** contextual function cues.
- **Extension.** nominalisation and adjective analysis.

For oral activities, supply enough context through audio or the scene so Devanagari literacy is not an assessment prerequisite.

### Initial target

- **Learner prompt.** What is being evaluated in the statement about freedom?
- **Expected response.** An idea, freedom.
- **Assessment target.** LO1. Record the response against this target separately from the other prototype.
- **Feedback and retry.** Compare with evaluating a chair and identify what each expression refers to.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.

### Contrast target

- **Learner prompt.** Which happiness example refers to happiness in a noun phrase and which describes the speaker?
- **Expected response.** Row 5 refers to happiness; row 6 describes the speaker's state.
- **Assessment target.** LO3. Record the response against this target separately from the other prototype.
- **Feedback and retry.** Point to the possessor and the predicate in each, then compare the functions before labelling.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.
