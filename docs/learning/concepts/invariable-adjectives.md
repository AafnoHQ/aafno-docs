## 2. Learning outcomes

- LO1: Recognise a constant form across matched examples.
- LO2: Distinguish an invariant pattern from a single observation.
- LO3: Use a reviewed constant form in a new context.
- LO4: Contrast it with an alternating descriptor.

## 3. Meaning and usage

An adjective can retain the same form in contexts where another adjective changes. Keep the comparison tied to the environments actually examined.

## 4. Formation rules

Compare the first three rows, holding the descriptor fixed while the noun referents change. Compare the alternating descriptor in the last two rows. Check the same property in a new setting without adding an ending mechanically.

**Worked models.** सुन्दर केटा / Sundar keta / A beautiful boy (Match the same descriptive meaning.) Compare सुन्दर केटी / Sundar keti / A beautiful girl (The noun changes while the adjective is constant.) The examples are instructional candidates.

## 5. Variations and agreement

Related constructions may change without the adjective itself changing. सफा / Saphaa / clean, खुसी / Khusi / happy, नयाँ / Nayaã / new and गम्भीर / Gambhir / serious need their own contextual comparisons before wider claims.

## 8. Anticipated mistakes and corrective feedback

A learner can sound plausible while using a cue unrelated to the target. Test what they inferred with the two independent prompts in section 12.

**Corrective cue for the first prompt.** Circle the noun differences, then compare what stays constant.

**Corrective cue for the second prompt.** If an ending was added, recall the matched contexts and retry with the reviewed unchanged form.

Use the [variant-aware assessment policy](../proficiency-framework.md#variant-aware-assessment) if context permits more than one answer or the variant has not been reviewed.

## 9. Natural usage

## 12. Activity types

References to rows are to section 6. Provide Devanagari, Romanisation and English by default. For unaided production, hide examples and target expressions until after the response. A scaffolded response is recorded as guided practice.

### First evidence target

- **Learner prompt.** Across rows 1–3, which form is unchanged?
- **Expected response.** सुन्दर / Sundar / beautiful.
- **Assessment target.** LO1 only. Score this response independently of the other activities.
- **Feedback and retry.** Circle the noun differences, then compare what stays constant.
- **Validation status.** Draft. Confirm naturalness, context and acceptable responses before scored use.

### Second evidence target

- **Learner prompt.** Describe a beautiful place in a Nepali noun phrase. Hide the model adjective forms first.
- **Expected response.** सुन्दर ठाउँ / Sundar thaaũ / a beautiful place.
- **Assessment target.** LO3 only. Score this response independently of the other activities.
- **Feedback and retry.** If an ending was added, recall the matched contexts and retry with the reviewed unchanged form.
- **Validation status.** Draft. Confirm naturalness, context and acceptable responses before scored use.

## 13. Mastery evidence

Use unseen matched examples, including an isolated form as an insufficient-evidence foil. Ask for an independently produced constant form in a distinct reviewed noun phrase. Record what learners actually identify, interpret, select or produce against the applicable local outcome. Keep uncertainty visible and avoid inferring one outcome from evidence for another.
