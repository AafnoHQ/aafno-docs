## 3. Meaning and usage

Sequence expressions order events relative to one another. First, after that and finally can help the listener follow a routine even when no clock time is given.

## 4. Formation rules

Put eating, working and resting on a timeline. Establish the first event before interpreting the after-that cue. If a new event intervenes, check which one the speaker refers back to before continuing.

**Worked models.** पहिले खाना खान्छु। / Pahile khaanaa khaanchhu. / First, I eat. (Open a routine report.) Compare त्यसपछि काम गर्छु। / Tyaspachhi kaam garchhu. / After that, I work. (The previous eating event is the anchor.) The examples are instructional candidates.

## 5. Variations and agreement

Sequence differs from clock time, duration and tense. Connectors or dependent temporal clauses can order events too; their construction belongs to G19, G20 or G22.

## 8. Anticipated mistakes and corrective feedback

A learner can sound plausible while using a cue unrelated to the target. Test what they inferred with the two independent prompts in section 12.

**Corrective cue for the first prompt.** Replay the cues and connect ‘after that’ to the previous action before trying again.

**Corrective cue for the second prompt.** If order is missing, think which expression picks up the meal and retry.

Use the [variant-aware assessment policy](../proficiency-framework.md#variant-aware-assessment) if context permits more than one answer or the variant has not been reviewed.
