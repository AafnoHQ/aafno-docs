## 2. Learning outcomes

- LO1: Distinguish category words and names.
- LO2: Recognise a multiword name.
- LO3: Explain why case typography is irrelevant in Devanagari.
- LO4: Identify definite reference with a common noun.
- LO5: Classify a new example from context.

## 3. Meaning and usage

A common noun can classify an entity; a proper name labels it. Devanagari does not distinguish uppercase and lowercase. An identifiable entity need not be named in an utterance.

## 4. Formation rules

Start with a category, pair it with a place name, then identify the same place by a contextually known common-noun phrase. For a multiword designation, test which full expression serves as the name.

**Worked models.** काठमाडौं एउटा सहर हो। / Kaathmaadaũ eutaa sahar ho. / Kathmandu is a city. Compare नेपाल एउटा देश हो। / Nepaal eutaa desh ho. / Nepal is a country. Use the situations in section 6 to establish the intended readings.

## 5. Variations and agreement

A name may contain a common noun. Context determines whether a phrase is a label or description in a given use; separate name status from number and definiteness.

## 8. Anticipated mistakes and corrective feedback

**Likely misunderstanding.** An English typographic cue can cause a learner to miss a proper name or classify any identifiable expression as one.

**Retry.** Ask which term could classify another river. For the contrast target, switch to a different map and reuse the same noun. Use the [variant-aware assessment policy](../proficiency-framework.md#variant-aware-assessment) for contextual mismatches and unreviewed forms.

## 9. Natural usage

**Draft usage scenario.** A guide names the place using row 1, then uses row 4 when the group has the map open. Continue with the itinerary label in row 5 and ask which place the group can identify. ## 10. Prerequisites

- **Required.** a context showing whether an entity is named.
- **Helpful.** basic place vocabulary.
- **Co-taught.** map and itinerary labels.
- **Extension.** definiteness and number contrasts.

For oral activities, supply enough context through audio or the scene so Devanagari literacy is not an assessment prerequisite.

## 12. Activity types

Row references below refer to the contextual examples in section 6. Use all three language representations by default; adjust visibility only for the evidence target.

### Initial target

- **Learner prompt.** Which expression names a particular river in row 3?
- **Expected response.** बागमती / Baagmati / Bagmati; नदी / Nadi / river gives the category.
- **Assessment target.** LO1. Record the response against this target separately from the other prototype.
- **Feedback and retry.** Ask which term could classify another river.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.

### Contrast target

- **Learner prompt.** Does ‘this city’ turn ‘city’ into a proper name?
- **Expected response.** No. It remains a common noun even when the speakers can identify the city.
- **Assessment target.** LO4. Record the response against this target separately from the other prototype.
- **Feedback and retry.** Switch to a different map and reuse the same noun.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.

## 13. Mastery evidence

Use unseen itinerary and map examples including a multiword label and a definite common noun. Require category versus name and the evidence, independent of typography. Record what the answer demonstrates against the local outcomes and keep stem, ending, case, agreement and related semantic evidence separate. Guided performance can inform feedback; mastery requires an independent task and flexible evidence where relevant.
