## 2. Learning outcomes

- LO1: Recognise explicit noun plural marking.
- LO2: Form a reviewed plural.
- LO3: Interpret number from contextual cues.
- LO4: Separate formation from number inference.
- LO5: Form the plural of a new reviewed noun.

## 3. Meaning and usage

A noun may display explicit plural marking, while number may also come from a numeral or context. These are distinct pieces of evidence.

## 4. Formation rules

Attach हरू / Haru / plural marker to a reviewed noun in the first three examples. Compare the result with an unmarked noun in a numerical phrase. Ask where the number information comes from in each.

**Worked models.** किताब / किताबहरू / Kitaab / Kitaabharu / Book / books Compare साथी / साथीहरू / Saathi / Saathiharu / Friend / friends Use the situations in section 6 to establish the intended readings.

## 8. Anticipated mistakes and corrective feedback

**Likely misunderstanding.** A learner may treat an unmarked noun as singular even when the phrase supplies a plural number.

**Retry.** If you used a number instead, retry by changing the noun form itself. For the contrast target, locate the numeral before checking the noun. Use the [variant-aware assessment policy](../proficiency-framework.md#variant-aware-assessment) for contextual mismatches and unreviewed forms.

## 9. Natural usage

**Draft usage scenario.** In an inventory exchange first record the explicit plural in row 1 and then use row 5 for a counted order. Ask which cue would remain if the number phrase were dropped. Check the turns with speakers in the intended context before using them as learner-facing models; no frequency or distribution is inferred.

## 10. Prerequisites

- **Required.** familiar noun referents.
- **Helpful.** basic count words.
- **Co-taught.** segmentation of reviewed plural forms.
- **Extension.** optional plural marking and classifier frames.

For oral activities, supply enough context through audio or the scene so Devanagari literacy is not an assessment prerequisite.

## 12. Activity types

Row references below refer to the contextual examples in section 6. Use all three language representations by default; adjust visibility only for the evidence target.

### Initial target

- **Learner prompt.** Produce an explicitly marked plural of the word for house.
- **Expected response.** घरहरू / Gharharu / houses.
- **Assessment target.** LO2. Record the response against this target separately from the other prototype.
- **Feedback and retry.** If you used a number instead, retry by changing the noun form itself.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.

### Contrast target

- **Learner prompt.** How many books are described in row 5, and is the noun marked?
- **Expected response.** Three; the noun has no explicit plural suffix.
- **Assessment target.** LO3. Record the response against this target separately from the other prototype.
- **Feedback and retry.** Locate the numeral before checking the noun.
- **Validation status.** Draft. Review the scenario, intended reading and accepted responses before use.

## 13. Mastery evidence

Ask for an explicitly marked plural of a new reviewed noun; separately ask for the number conveyed by an unmarked numeric phrase and an ambiguous bare noun. Record what the answer demonstrates against the local outcomes and keep stem, ending, case, agreement and related semantic evidence separate. Guided performance can inform feedback; mastery requires an independent task and flexible evidence where relevant.
