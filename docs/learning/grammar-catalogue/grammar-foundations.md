# Grammar foundations

[Grammar catalogue](index.md) · Phase 2A.2 Step 2

This batch contains **55 planned learner targets** in G01–G06. The reconciliation is structurally approved and its repository implementation has been merged. All examples, language classifications and usage claims remain drafts pending linguistic and native-speaker validation. [Traceability and approved boundaries](traceability-1.md).

Each heading identifies the coverage category for its entries. The related categories below each table record shared coverage and linked applications.
